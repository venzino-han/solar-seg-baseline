# Solar 세그멘테이션 데이터셋 (코로나홀 · 흑점 · 홍염)

작성일 2026-11-26 (11-22 판에서 레이블이 없던 박스 934개를 채움)

SDO 태양 관측 영상 12,394장과, 각 영상에 표시된 박스마다 만든 픽셀 단위 세그멘테이션 레이블을 클래스별로 묶은 데이터셋이다.
레이블은 **사람 레이블이 있으면 사람 레이블**, 없으면 **파인튜닝한 SAM 3가 만든 레이블**이다. 모든 박스에 레이블이 있다. 어느 쪽인지는 `labels.csv`의 `label_source` 열에 박스마다 적혀 있다.

## 1. 구성

| 파일 | 클래스 | 채널 | 이미지 (train / test) | 박스 |
| --- | --- | --- | --- | --- |
| `solar_coronal_hole_seg.zip` | 코로나홀 | SDO/AIA 193Å | 5,085 (4,068 / 1,017) | 9,984 |
| `solar_sunspot_seg.zip` | 흑점 | SDO/HMI 연속광 | 4,383 (3,500 / 883) | 11,244 |
| `solar_prominence_seg.zip` | 홍염 | SDO/AIA 304Å | 2,926 (2,340 / 586) | 9,241 |

세 zip의 내부 구조는 같다.

```
solar_<class>_seg/
├── DATASET.md                          이 문서
├── labels.csv                          박스 1개 = 1행. 이미지·박스·레이블 매칭표
├── images/<split>/<stem>.jpg           원본 이미지 (512×512 컬러 JPEG, 변경 없음)
├── boxes/<split>/<stem>.xml            원본 박스 (Pascal VOC XML)
├── masks/<split>/<stem>__b<i>.png      박스별 레이블 마스크 (i = 박스 번호)
└── masks_full/<split>/<stem>.png       이미지별 레이블 마스크 (그 이미지의 박스별 마스크 합집합)
```

- `<split>`은 `train` 또는 `test`이고, 받은 원본의 분할을 그대로 따른다.
- `<stem>`은 `YYYYMMDD_HHMMSS_SDO_<채널>_512` 형식의 원본 파일 이름이다. 촬영 연도는 2010–2019년이다.
- 마스크는 512×512 단일 채널 PNG이고 값은 0(배경) 또는 255(레이블)이다. 좌표계는 원본 이미지와 같다.
- `masks_full`은 모든 이미지에 하나씩 있다. 레이블이 하나도 없는 이미지는 전부 0이다.
- `boxes`의 XML은 원본에서 `<path>` 항목(작성 당시 PC의 절대 경로)만 파일 이름으로 바꿨다. 박스 좌표와 클래스 이름은 원본 그대로다.

## 2. labels.csv

| 열 | 뜻 |
| --- | --- |
| `split`, `stem` | 분할, 이미지 이름 |
| `box_index` | 이미지 안의 박스 번호. XML에 적힌 순서이며 0부터 시작 |
| `xmin`, `ymin`, `xmax`, `ymax` | 박스 좌표 (픽셀) |
| `label_source` | `human` = 사람 레이블, `sam3` = 파인튜닝 SAM 3 레이블, `sam3_retry` = 같은 모델로 조건을 바꿔 다시 만든 레이블, `rule` = 밝기 규칙으로 만든 레이블 |
| `human_edited` | 사람 레이블일 때만 값이 있다. 1 = 사람이 마스크를 직접 고침, 0 = 모델 초안을 사람이 보고 그대로 승인 |
| `area_px` | 레이블 마스크의 픽셀 수 |
| `model_score` | SAM 3 레이블일 때만 값이 있다. 코로나홀은 모델 신뢰도, 흑점·홍염은 밝기 기준 영역과의 일치도(IoU) |
| `image_path`, `box_path`, `mask_path`, `mask_full_path` | zip 안의 상대 경로 |

## 3. 레이블 수

| 클래스 | 사람 (`human`) | SAM 3 (`sam3`) | SAM 3 재생성 (`sam3_retry`) | 밝기 규칙 (`rule`) | 합계 |
| --- | --- | --- | --- | --- | --- |
| 코로나홀 | 72 | 9,911 | 1 | 0 | 9,984 |
| 흑점 | 45 | 10,348 | 801 | 50 | 11,244 |
| 홍염 | 133 | 9,026 | 81 | 1 | 9,241 |

분할별:

| 클래스 | train: SAM 3 / 재생성 / 규칙 | test: 사람 / SAM 3 / 재생성 / 규칙 |
| --- | --- | --- |
| 코로나홀 | 7,933 / 1 / 0 | 72 / 1,978 / 0 / 0 |
| 흑점 | 8,241 / 648 / 35 | 45 / 2,107 / 153 / 15 |
| 홍염 | 7,345 / 72 / 1 | 133 / 1,681 / 9 / 0 |

- 사람 레이블은 모두 test 분할에 있다.
- 사람 레이블 중 사람이 직접 고친 것은 코로나홀 45건, 흑점 41건, 홍염 127건이고, 나머지는 모델 초안을 그대로 승인한 것이다.
- 마스크 면적 중앙값(사람 / SAM 3): 코로나홀 2,729 / 2,531px, 흑점 95 / 69px, 홍염 1,061 / 562px.
- 박스가 하나도 없는 이미지가 코로나홀 2장, 흑점 2장, 홍염 6장 있다. 박스는 있지만 레이블이 하나도 없는 이미지는 흑점에만 78장 있다.

## 4. 원본 데이터

- 512×512 컬러 JPEG 1장에 Pascal VOC XML 1개가 짝을 이루는 객체탐지용 데이터로 제공받았다. XML에는 클래스 이름과 박스 좌표만 있고 픽셀 마스크는 없었다.
- train/test 분할은 받은 그대로이며, 분할 기준과 박스를 그린 기준은 전달받지 못했다.
- 2010–2011년 프레임이 2016–2017년 프레임보다 약 3배 밝게 렌더링되어 있다. 일부 프레임에는 캡션 글자가 새겨져 있다.

## 5. 레이블을 만든 방법

1. 박스를 프롬프트로 SAM 3에 넣어 초안 마스크를 만들었다.
2. test 분할에서 뽑은 박스의 초안을 사람이 웹 편집기에서 고치거나 승인했다. 이것이 사람 레이블이다.
3. 사람 레이블로 SAM 3의 마스크 디코더와 프롬프트 인코더만 파인튜닝했다(영상 인코더는 고정).
4. 파인튜닝한 SAM 3로 train+test의 모든 박스를 다시 레이블했다.
5. 자동 품질 검사를 통과한 마스크를 `sam3` 레이블로 넣었다.
6. 통과하지 못한 박스 934개는 같은 모델에 프롬프트·박스 여백·임계값을 바꿔 넣어 다시 만들고, 같은 품질 검사를 통과한 마스크를 `sam3_retry` 레이블로 넣었다(883개). 흑점은 태양 가장자리 박스가 대부분이어서 원반 영역을 실제 가장자리까지 넓혀 다시 만들었다.
7. 그래도 통과한 마스크가 없는 박스 51개는 박스 안의 밝기 규칙으로 채웠다(`rule`). 흑점은 같은 반지름의 주변보다 12% 이상 어두운 픽셀, 홍염은 원반 밖에서 박스 안 하늘보다 밝은 픽셀이며, 해당 픽셀이 최소 크기에 못 미치면 가장 어두운(밝은) 픽셀을 최소 크기만큼 넣었다.
8. 사람 레이블이 있는 박스는 모델 마스크 대신 사람 레이블을 넣었다.
9. 최종 SAM 3 레이블의 품질은 샘플링한 레이블을 전문가가 검수해 확인했다.

| 클래스 | 파인튜닝에 쓴 레이블 | 품질 검사 | 사람 레이블 대비 IoU (파인튜닝 전 → 후) |
| --- | --- | --- | --- |
| 코로나홀 | 사람 72건 | 면적 ≥ 60px, 박스 점유율 0.05–0.90, 모델 신뢰도 ≥ 0.30 | 0.687 → 0.793 |
| 흑점 | 사람 45건 | 면적 ≥ 4px, 박스 점유율 ≤ 0.90, 주변 광구보다 어두움 | 0.633 → 0.715 |
| 홍염 | 사람 133건 + 합성 7,599건 | 면적·박스 점유율·밝기 조건 | 0.26 → 약 0.64 |

- 코로나홀·흑점의 IoU는 날짜를 분리한 5-fold 교차검증 값이다.
- 홍염의 IoU는 사람 레이블이 33건이던 시점의 교차검증 값이다. 최종 모델은 133건을 모두 학습에 써서 따로 떼어 둔 평가 점수가 없다.
- 홍염의 합성 데이터는 train 분할 이미지 위에 가짜 홍염을 그려 넣고 그 모양을 정답으로 쓴 것이다. 이 데이터셋에는 들어 있지 않다.

클래스별 마스크 규칙:

- 코로나홀: 태양 원반 안쪽, 박스 안쪽으로 잘랐다.
- 흑점: 태양 원반 안쪽, 박스 안쪽으로 잘랐다.
- 홍염: 자르지 않았다. 마스크가 박스 밖이나 태양 원반 안쪽으로 이어질 수 있다.
- 사람 레이블은 사람이 칠한 그대로이며 박스 밖으로 나갈 수 있다.

## 6. 쓸 때 알아 둘 점

- 최종 SAM 3 레이블의 품질은 샘플링을 통해 전문가 검수를 거쳤다. 전수 검수는 아니므로 개별 레이블에는 오류가 있을 수 있다.
- **정정 요청은 언제든 열려 있고 환영한다.** 잘못된 레이블을 발견하면 `labels.csv`의 `split`, `stem`, `box_index`와 함께 알려 주면 반영한다.
- `sam3_retry` 레이블은 처음 품질 검사에서 떨어진 박스라 대상이 작거나 흐리다(넓이 중앙값: 흑점 26px, 홍염 192px). `rule` 레이블 51개는 모델이 아니라 밝기 규칙으로 만든 것이고 대부분 4px 크기라 품질이 가장 낮다. 빼고 쓰려면 `label_source`로 거르면 된다.
- 홍염은 학습에 쓰지 않은 test 이미지의 `sam3` 레이블 일부를 사람이 조회해 검수했다. 343건 판정 중 305건이 "확인", 38건이 "수정필요"였고, 이 검수 결과는 레이블에 반영하지 않았다.
- 사람 레이블이 모두 test 분할에 있고 모델이 그 레이블로 학습했다. 이 데이터셋의 test로 다른 모델을 평가해도 완전히 독립된 평가는 아니다. 사람 레이블만으로 평가하려면 `label_source == human`인 행만 쓰면 된다.
- 홍염 사람 레이블 대부분은 모델 초안을 고친 것이라 모델 마스크와 닮는 쪽으로 치우쳐 있다.
- 홍염은 레이블 기준(원반 안쪽 뿌리를 포함할지, 고리 안 빈 곳을 채울지)이 사람마다 달랐다. 같은 대상에 대한 사람 간 IoU가 0.57이었다.
- 레이블은 박스가 있는 대상에만 있다. 박스가 없는 대상은 영상에 보여도 배경으로 남는다.
- 레이블 파일이 모든 박스에 있고 최소 픽셀 수(코로나홀 60, 흑점 4, 홍염 8) 이상인지 규칙 기반 코드로 전수 확인했다. 예외는 박스 자체가 3×2px인 홍염 1건(6px)뿐이다.
- 흑점 사람 레이블은 2010–2013년 프레임에만 있다.
